# Paperless — Delivery outcomes

- [x] **Naming and migration-friendly PWA foundation**
  - Offer suggested app names with **Paperless** preselected and support manual name entry.
  - Build Paperless as an installable, offline-capable PWA with responsive mobile UX, local autosave, camera-permission guidance, and a modular codebase that can later move to a native app.
  - Use free and open-source resources; do not require paid scanning, OCR, storage, or export services.

- [x] **Camera-first scanning and multipage capture**
  - Provide camera-first document capture with image import as a fallback.
  - Support automatic page detection, edge highlighting, crop adjustment, perspective correction, and rotation.
  - Support a multipage scanning workflow with page reordering, duplication, deletion, and rescanning.

- [x] **Scan processing and document markup**
  - Provide scan enhancement tools for auto-cleanup, grayscale, black-and-white, color, contrast, and shadow reduction.
  - Provide document editing tools for page markup, redaction, signatures, and password protection where browser support permits.

- [x] **On-device OCR and local document library**
  - Provide free on-device OCR for selectable text, document search, and copyable scan content.
  - Provide a local document library with thumbnails, custom titles, folders or tags, sorting, and search.

- [x] **Document export and sharing**
  - Provide PDF and image export with quality or file-size controls.
  - Support download, print, and Web Share options.
